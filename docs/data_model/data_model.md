# Модель даних CoffeeMap

## Опис проєкту
CoffeeMap - це інтелектуальний гід по найкращим кав'ярням навколо вас. Додаток дозволяє знаходити кав'ярні через пошук за адресою, переглядати їх на інтерактивній карті та отримувати детальну інформацію про заклади.

## User Stories

### US-001: Відображення кав'ярень на карті
**Як студент**, я хочу бачити всі кав'ярні на карті навколо мого університету, щоб швидко знайти найближчий заклад.

**Задіяні сутності:** CoffeeShop, SearchHistory

### US-002: Пошук за адресою
**Як абітурієнт**, я хочу ввести адресу університету в пошук, щоб карта автоматично показала мені кав'ярні саме біля нього.

**Задіяні сутності:** CoffeeShop, SearchHistory

### US-003: Перегляд деталей кав'ярні
**Як користувач**, я хочу натискати на позначку кав'ярні на карті, щоб побачити її назву, адресу та години роботи.

**Задіяні сутності:** CoffeeShop

## Сутності та їх атрибути

### 1. CoffeeShop (Кав'ярня)

| Назва атрибуту | Тип даних | Опис | Обмеження |
|----------------|-----------|------|-----------|
| id | INTEGER | Унікальний ідентифікатор | PRIMARY KEY, AUTO_INCREMENT |
| name | VARCHAR(200) | Назва кав'ярні | NOT NULL |
| address | VARCHAR(255) | Адреса закладу | NOT NULL |
| latitude | DECIMAL(10,8) | Географічна широта | NOT NULL |
| longitude | DECIMAL(11,8) | Географічна довгота | NOT NULL |
| phone | VARCHAR(20) | Номер телефону | NULL |
| opening_hours | TEXT | Години роботи | NULL |
| external_place_id | VARCHAR(255) | ID місця з Google Maps API | UNIQUE, NOT NULL |
| created_at | TIMESTAMP | Дата додавання в кеш | DEFAULT CURRENT_TIMESTAMP |
| updated_at | TIMESTAMP | Дата останнього оновлення | DEFAULT CURRENT_TIMESTAMP ON UPDATE |

**Призначення:** Кешування інформації про кав'ярні, отриманої з Google Maps API, для зменшення кількості запитів до зовнішнього сервісу.

**Бізнес-логіка:**
- Дані оновлюються при кожному новому запиті користувача
- Якщо кав'ярня вже є в кеші (за external_place_id), оновлюється тільки updated_at
- Застарілі записи (старше 30 днів) можуть видалятися

### 2. SearchHistory (Історія пошуку)

| Назва атрибуту | Тип даних | Опис | Обмеження |
|----------------|-----------|------|-----------|
| id | INTEGER | Унікальний ідентифікатор | PRIMARY KEY, AUTO_INCREMENT |
| search_address | VARCHAR(255) | Адреса пошуку | NOT NULL |
| search_latitude | DECIMAL(10,8) | Широта точки пошуку | NOT NULL |
| search_longitude | DECIMAL(11,8) | Довгота точки пошуку | NOT NULL |
| radius | INTEGER | Радіус пошуку в метрах | DEFAULT 1000 |
| results_count | INTEGER | Кількість знайдених кав'ярень | DEFAULT 0 |
| search_timestamp | TIMESTAMP | Час виконання пошуку | DEFAULT CURRENT_TIMESTAMP |

**Призначення:** Збереження історії пошукових запитів для аналітики та можливості відображення популярних локацій.

**Бізнес-логіка:**
- Зберігається кожен пошуковий запит користувача
- Дані використовуються для аналітики популярних локацій
- Можливість очищення старої історії (старше 90 днів)

## Зв'язки між сутностями

У даній версії MVP сутності **не мають прямих зв'язків**, оскільки:
- CoffeeShop - це кеш даних з Google Maps API
- SearchHistory - це лог пошукових запитів

Обидві таблиці працюють незалежно одна від одної.

## Індекси

Для оптимізації продуктивності створюються наступні індекси:

### CoffeeShop
- `idx_coffeeshop_location` на (latitude, longitude) - для швидкого геопросторового пошуку
- `idx_coffeeshop_external_id` на (external_place_id) - UNIQUE, для перевірки наявності в кеші
- `idx_coffeeshop_updated` на (updated_at) - для очищення застарілих записів

### SearchHistory
- `idx_search_location` на (search_latitude, search_longitude) - для аналітики популярних локацій
- `idx_search_timestamp` на (search_timestamp) - для очищення старої історії

## Бізнес-правила

1. **Кешування даних:**
   - Кав'ярні зберігаються в базі даних після першого запиту
   - Якщо кав'ярня вже є (перевірка по external_place_id), оновлюється updated_at
   - Дані вважаються актуальними протягом 30 днів

2. **Пошук:**
   - Кожен пошуковий запит логується в SearchHistory
   - Радіус пошуку за замовчуванням - 1000 метрів (1 км)
   - Координати точки пошуку отримуються через геокодування введеної адреси

3. **Відображення:**
   - На карті відображаються всі кав'ярні в радіусі від точки пошуку
   - При натисканні на маркер показується інформація з таблиці CoffeeShop

4. **Очищення даних:**
   - CoffeeShop: записи старші 30 днів можуть видалятися
   - SearchHistory: записи старші 90 днів можуть видалятися

## Майбутні розширення (не входять в поточний MVP)

Якщо проєкт буде розвиватися, можливо додавання:
- **User** - для реєстрації користувачів
- **Review** - для відгуків та оцінок
- **Favorite** - для збереження улюблених кав'ярень
- **University** - якщо з'явиться список університетів

Але на даний момент ці сутності **не потрібні** для реалізації описаних user stories.
